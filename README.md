# Job Tracker

A simple and responsive web application to manage and track job applications in one place.

## 🚀 Live Demo

https://vaishnavikadtan.github.io/Job-Tracker/

## 📂 GitHub Repository

https://github.com/VaishnaviKadtan/Job-Tracker

## ✨ Features

- Add new job applications
- Edit existing job applications
- Delete job applications
- Search jobs by company or role
- Filter applications by application status
- Dashboard with application statistics
- Stores job data using LocalStorage
- Data remains saved after refreshing the page
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📊 Dashboard

The dashboard provides an overview of job applications:

- Total Jobs
- Applied Jobs
- Interview Opportunities
- Selected Jobs

## 📋 Job Application Details

Each job application includes:

- Company Name
- Job Role
- Applied Date
- Application Status

Available statuses:

- Applied
- Interview
- Selected
- Rejected

## 💾 Data Storage

This project uses the browser's LocalStorage to store job application data.

The data remains available even after refreshing or reopening the browser on the same device.
